# Karah Portfolio

A simple personal portfolio website for Fred Karah, built with HTML and CSS.

## Overview

This project showcases a basic online portfolio with sections for:

- About me
- Interests
- Skills
- Contact information
- Project navigation

## Project Files

- `index.html` — main landing page
- `fred 2.jpg.jpeg` — profile image
- Additional pages such as `about.html`, `services.html`, `contact.html`, and `project.html` can be added or linked as the portfolio grows
